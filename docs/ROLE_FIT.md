# Fit to ARC IT Project Coordinator — reference 303983

**Primary directly matched requirement:** designing a process to calculate and allocate EV charging costs. This independent software exercise calculates *candidate* variable-energy costs under declared metering and tariff assumptions, and creates a human-reviewed exceptions process. It does not provide a commercially approved allocation or invoice.

**Second requirement:** AI automation to make operations faster. The deterministic engine automates CSV validation, reconciliation and exception sorting. An *optional* server-side language-model endpoint can draft next investigation checks from source-identified exceptions; it is disabled by default and its suggestions are never financial inputs.

**Supportive requirement:** organise stakeholders and create repeatable procedures. The action register includes named owner, due date, next check, disposition and review history. This is portfolio work, not a claim of actual organisational adoption. The candidate's separate University Living tool is real-world adoption evidence.

**Not evidenced:** solar installation performance assessment, physical installation delivery, site commissioning, legal billing treatment, live EV integrations, or time saving in a real business. Do not claim them.

**Connection to LightYield manuscript:** both prefer rules/constraints that can be independently checked and human approval for consequential operations. The manuscript is unpublished and does not prove field-validated savings.
